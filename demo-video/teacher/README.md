- Admin-only center Settings, team Staff list, Rooms, Supplies, Report center,
  Smart list, Smart forms, Surveys, Performance, Finance, Account billing,

  pilot and reported for a role-gate decision.

## Reproduce

From `demo-video/teacher`:

```sh
npm run setup
# installs dev deps (--include=dev: sandbox NODE_ENV=production otherwise
# skips them), downloads Playwright Chromium, and verifies ffmpeg/ffprobe
# via ffmpeg-static — no system packages needed
python3 -m pip install --break-system-packages edge-tts  # for the TTS WAVs
node capture/build-manifest.mjs     # line lists + capture plans
node capture/print-scripts.mjs      # scripts/en.md, scripts/ar-eg.md
```

Bind the demo login as secrets on the agent, never in a file:

```sh
# supplied by Paperclip secret bindings, not committed
export KIDDY_TEACHER_EMAIL=...
export KIDDY_TEACHER_PASSWORD=...
```

English capture:

```sh
node capture/auth.mjs --lang en
node capture/record.mjs --lang en
```

Arabic capture (real RTL UI; the account language is switched in Account
settings, not faked in editing):

```sh
node capture/auth.mjs --lang ar
node capture/record.mjs --lang ar
```

The portal renders from `account.language`, so run the matching `auth` first.
`auth.mjs` now switches either direction and `record.mjs` stops if `<html lang>`
does not match `--lang`; do not record the EN batch after the AR batch without
re-running `auth --lang en`.

Voiceover WAVs (generated by the TTS script into `voiceover/wav/<lang>/`, one
file per scene id — see `voiceover/README.md`):

```sh
npm run wavs:en
npm run wavs:ar
node capture/assemble.mjs --lang en
node capture/assemble.mjs --lang ar
node capture/check.mjs --require-final
```

Outputs land in `out/<lang>/` (gitignored):

- `teacher-en-1080p.mp4`, `teacher-ar-1080p.mp4` — 1920×1080, 30 fps CFR, H.264/AAC, −16 LUFS
- `teacher-en.srt`, `teacher-ar.srt` — one cue per scene, same language as the VO
- `scene-timestamps.csv` — scene, tool, route, start, end, duration, VO present
- `assembly.json`, `selfcheck.json` — machine-readable evidence

Visible email addresses are replaced with `teacher@sunshine.demo` during
capture by default (`MASK_EMAILS=0` disables it only for an already-public fake
address). This keeps a demo login from becoming on-screen personal data.

A single-scene retry for selector tuning:

```sh
node capture/record.mjs --lang en --only 02-dashboard
```

The capture runner needs a Playwright Chromium with its system libraries
(`npx playwright install --with-deps chromium`). Set `PLAYWRIGHT_MODULE`,
`CHROMIUM_EXECUTABLE`, `FFMPEG`, or `FFPROBE` only when the runner uses
non-default paths.

## Voiceover

See `voiceover/README.md`. The board selects his own cloned voice in Voicebox
and runs `voiceover/voicebox-batch.example.sh en|ar`. The repo holds only the
line list, language, and output filename.

Timing is deliberately two-stage: the CSV `duration` is a planning target; the
assembler re-measures every uploaded WAV and stretches or trims that scene, so
sync survives a different read speed.

## Self-check before review

`capture/check.mjs` verifies 1920×1080, 30 fps, duration, one cue per scene,
one timestamp row per scene, every WAV present, and that no credential or real
email is in the source tree. The manual checklist stays in the output:

- No real child, parent, or staff data is visible.
- No credential, demo email, or password is readable on screen or in captions.
- Arabic is the real RTL UI (mirrored shell), not a flipped edit.
- Every visible teacher tool appears in the scene list.
- Captions match the spoken line and stay up for that line.
- No admin-only screen appears.

## UI defects found while building the scene map

Reported to the PM/CEO; no product code was changed by this task.

1. **Teacher dashboard links to admin-only surfaces.** The cards link to
   `/portal/rooms` (redirects a teacher back to the dashboard), the Report
   center, and `/portal/forms?view=inquiries`. The teacher also sees a
   "Demo inquiries" card.
2. **Teacher dashboard counts are center-wide.** Pending consents,
   unacknowledged incidents, staff, and inquiries are not scoped to the
   teacher's assigned classrooms, while children and attendance are scoped.
3. **Child Invoices tab and Manage billing are visible to teacher accounts.**
   Excluded from the pilot pending a role-gate decision.
4. **Admin Tools routes are not server-gated.** `/portal/forms` and the other
   Tools pages render for a teacher who types the URL, even though the sidebar
   hides them. Confirm the intended role gate with QA.
5. **Arabic coverage is incomplete on teacher pages.** The shell is RTL, but
   Attendance, Staff schedule, Working hours, Incidents, Calendar, and Parent
   drive still render hardcoded English. The Arabic video will show mixed
   languages until those surfaces are localized.
6. **The Sunshine brand banner is the Kiddy wordmark.** The tenant's uploaded
   brand image appears at the top of every captured page, so the Sunshine demo
   currently shows Kiddy branding. Update the tenant brand image before final
   capture, or accept the banner on screen.
