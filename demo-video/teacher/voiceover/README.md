# Teacher demo voiceover

Two ways to produce the WAVs:

1. **Automatic TTS (default).** `capture/gen-wavs.py` synthesizes every line
   with Microsoft Edge neural TTS and writes the WAVs itself. No API key, no
   recording session. English uses `en-US-AndrewMultilingualNeural`, Egyptian
   Arabic uses `ar-EG-SalmaNeural` (override with `--voice`).
2. **Human Voicebox (optional).** The board can still record these lines in
   Voicebox on his own machine with his own cloned voice. This repository
   never receives, stores, or commits a voice sample. Generate the TTS set
   first, then overwrite individual WAVs with the recorded ones — the
   generator never touches existing files unless `--force` is passed.

## Files

| File | Purpose |
| --- | --- |
| `en.lines.csv` | Final English line list: `id,text,scene,duration,...`. |
| `ar.lines.csv` | Final Egyptian Arabic line list, same shape. |
| `voicebox-batch.en.json` | Machine-readable batch for English: line id, text, language, output path. |
| `voicebox-batch.ar.json` | Machine-readable batch for Arabic. |
| `voicebox-batch.example.sh` | Local batch runner template. Fill in your Voicebox invocation. |
| `wav/en/<scene-id>.wav` | English WAVs (gitignored; generated by the TTS script or dropped here). |
| `wav/ar/<scene-id>.wav` | Arabic WAVs (same). |

The `duration` column is the planning target at 2.45 words/sec (English) and
2.2 words/sec (Arabic). Assembly re-measures each WAV and stretches or trims
that scene, so a slower or faster read does not break sync.

## Automatic TTS generation

From `demo-video/teacher`, after `npm run setup` and
`python3 -m pip install --break-system-packages edge-tts`:

```sh
npm run wavs:en          # all 28 English WAVs
npm run wavs:ar          # all 28 Egyptian Arabic WAVs (when Arabic unblocks)
# selective / custom voice:
python3 capture/gen-wavs.py --lang en --only 01-login,02-dashboard --force --rate +5%
```

Requires network access to the Edge Read Aloud endpoint; no API key.
ffmpeg comes from `ffmpeg-static` (installed by `npm run setup`).

## Local Voicebox run (optional human path)

1. Open Voicebox on your machine and select your own cloned voice.
2. Set `VOICE_ID` and `VOICEBOX_CMD` in the shell. `VOICEBOX_CMD` must read the
   line from `LINE_TEXT_FILE` and write a WAV to `OUT_FILE`.
3. Run from `demo-video/teacher`:

```sh
VOICE_ID=<your-voice-id> \
VOICEBOX_CMD='<your voicebox command> --voice "$VOICE_ID" --text-file "$LINE_TEXT_FILE" --out "$OUT_FILE"' \
bash voiceover/voicebox-batch.example.sh en
```

4. Repeat with `ar` and the Arabic voice/lexicon.
5. Check that `voiceover/wav/en/` and `voiceover/wav/ar/` contain one WAV per
   scene id (28 files each), then hand the task back for assembly.

Never paste the voice sample, a credential, or the cloned-voice ID into the
repository, a task comment, or a document.
